Privacidad del correo de Catálogo Dell

Actualización: 29 de octubre de 2026.

Esta política describe el uso de datos por el adaptador de correo Catálogo Dell, administrado por Garblac. Su finalidad es enviar mensajes transaccionales de Catálogo, incluidos mensajes de recuperación de acceso.

Acceso a Google y finalidad

El administrador concede acceso a su cuenta remitente mediante OAuth de Google. Se solicita exclusivamente el permiso gmail.send para enviar los mensajes generados por el servicio de autenticación. No se solicitan permisos para consultar mensajes existentes, contactos, archivos adjuntos de la bandeja de entrada ni para eliminar correos.

Datos utilizados y proveedores

Para realizar cada envío se procesa la dirección del destinatario, el remitente, el asunto y el contenido del mensaje. Este contenido puede incluir un enlace o código temporal de autenticación generado por Supabase Auth, alojado en el Dell.

El mensaje se transmite a Google mediante Gmail API para su entrega al proveedor de correo del destinatario. Los mensajes y sus copias también quedan sujetos a la configuración y las políticas de los servicios de correo implicados. Los datos de Google no se venden, no se usan para publicidad ni para entrenar modelos de inteligencia artificial.

Almacenamiento y acceso

Las credenciales y autorizaciones OAuth necesarias para operar el envío se conservan en equipos administrados por el responsable, con acceso restringido, y no se publican en el sitio web ni en el repositorio de código. El adaptador utiliza HTTPS para comunicarse con Google y no registra el contenido de los mensajes ni sus enlaces de recuperación en sus registros operativos.

Las autorizaciones se conservan mientras sean necesarias para prestar el servicio y pueden reemplazarse durante tareas de mantenimiento. Cualquier copia administrativa de credenciales debe mantenerse con acceso restringido y eliminarse cuando deje de ser necesaria.

Revocación y solicitudes

El titular de la cuenta remitente puede revocar el permiso desde las conexiones de su cuenta de Google. Revocar el permiso impide nuevos envíos con esa autorización; no elimina los mensajes ya entregados.

Para consultar el tratamiento de los datos o solicitar la eliminación de autorizaciones almacenadas, contacta con garblac01@gmail.com.
